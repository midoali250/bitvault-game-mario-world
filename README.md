# Super Mario Bros. (World) — private game source

This private repository holds the Android and desktop game projects, copied as a migration baseline from `bitvault-engine` at commit `1c5d32cd71c818b895ceb46c43690a017ebb0d9b`.

- Android: `games/super-mario-world/`
- Windows, Linux and macOS: `desktop/`

This is an initial compatibility snapshot: shared engine sources and the updater are temporarily included so the game can still build. Existing releases and update catalogs remain at their current locations until a separately tested publication migration. No new player release is created by this import.
